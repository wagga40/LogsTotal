{# Zoomable events timeline — individual matched alerts as pannable/zoomable markers. Shared verbatim by the job analytics page and the case Timeline tab, like _timeline_chart.html above it. Complements the hourly MITRE histogram (which answers "when was it busy") rather than replacing it: this answers "what fired, exactly when". Callers pass: tl_url — the events-timeline endpoint for this surface tl_state_key — namespaces the zoom in the `timelineRange` store ("job:12" / "case:3") The x-data lives on this root element, so every binding inside has an ancestor even when the partial is fetched standalone. Single-quoted because the JSON interpolation contains double quotes. There is deliberately no x-init self-call and no explicit destroy hook — Alpine 3 invokes init() and destroy() on the x-data object automatically, and doubling init() would mount two canvases over the same container. #}
