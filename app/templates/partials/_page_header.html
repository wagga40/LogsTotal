{# The page header every top-level page and every admin sub-page wears. Two destinations, and the distinction is the point: * a **top-level page** goes back to Home (`/`); * an **admin sub-page** goes back to `/admin#manage` — the Manage tab it was launched from, not the Overview tab a bare `/admin` lands on. `#manage` works because `resourceTabs.init()` reads `location.hash` on load (`app/static/app.js`). It works for a **cross-page** link only: the component registers no `hashchange` listener, so a same-document `#manage` link would move the URL and leave the pane where it was. Never put one of these on `/admin` itself. There is deliberately **no `intro` parameter**. Four of the pages that want one need Jinja inside it (a pluralised count) or a literal em-dash that autoescaping would mangle into `&mdash;`, so a shared parameter would be bypassed by a fifth of its call sites. Each page writes its own `

` underneath. It has to be a parameter rather than the `{% call %}` slot, because that slot is on the far right and already spoken for by the action button. {{ page_header('Users', '/admin#manage', 'Manage', pills=[('%d users' % total_users, 'gray'), ('%d admins' % total_admins, 'blue')]) }} #} {% from "partials/_count_pill.html" import count_pills %} {% macro page_header(title, back_href='', back_label='', pills=None) %} {# `items-center`, not `items-start`: the back link sits inline beside the title, so a right-hand action has to level with the 24px heading rather than the 14px link. Both halves of `back` are required together — with two independent arguments a caller can pass the label alone and get an unlinked word floating in the header, which renders perfectly and does nothing.
